# QuestAvailabilityIndicator

Plugin BetterDiscord qui conserve le bouton de lancement des quêtes acceptées et affiche un indicateur des quêtes disponibles non acceptées.

## Installation

1. Télécharge `QuestLaunchButton.plugin.js` depuis ce dépôt privé.
2. Place-le dans le dossier des plugins BetterDiscord (`%AppData%/BetterDiscord/plugins`).
3. Dans Discord, ouvre **Paramètres utilisateur → Plugins** et active `QuestLaunchButton`.

Pour synchroniser sur un autre ordinateur, connecte-toi à GitHub avec ton compte, clone ce dépôt privé, puis copie le fichier dans le dossier des plugins de BetterDiscord sur cet ordinateur.
